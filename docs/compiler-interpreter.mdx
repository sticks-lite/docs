# Interpreter Notes

Sticks Lite uses an interpreter pipeline. The language core does not read files
or write to the terminal directly.

## Pipeline

```txt
source text
lexer
parser
program AST
function pre-scan
interpreter
RuntimeIO
```

## Why this matters

- The CLI can read files without putting file APIs into the language.
- The browser IDE can provide input and output through the same runtime API.
- Tests can run programs without a terminal.
- Friendly errors can point to the same line and column across tools.

## Runtime values

```txt
number
text
boolean
null
list
tuple
dictionary
function
builtin
```

Lists and dictionaries are mutable. Tuples are immutable.

## Functions

Function definitions are collected before top-level code runs. This allows a
student to call a function before its definition appears in the file.

```slite
say toText(double(5))

new double(x):
    return x * 2
```

## Boundaries

The interpreter core receives source text and `RuntimeIO`. The Node.js CLI is
responsible for:

- reading `.slite` files
- resolving `main.slite`
- terminal input
- terminal output
- path error messages

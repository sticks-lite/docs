# API and Embedding

The `sticks-lite` package exposes a small TypeScript API for tools that embed
the language.

```ts
import {
  SticksLiteError,
  isSticksLiteError,
  lex,
  parse,
  runSource,
  type RunResult,
  type RuntimeIO,
} from "sticks-lite";
```

## `lex(source)`

Converts source text into positioned tokens.

```ts
const tokens = lex('say "Hello"');
```

Use this for editor tooling, syntax checks, or lessons about how source text is
read.

## `parse(source)`

Returns a program AST.

```ts
const program = parse("if True:\n    say \"yes\"\n");
```

Parser failures throw `SticksLiteError`.

## `runSource(source, io?)`

Runs a complete program and returns a `RunResult`.

```ts
const output: string[] = [];

const result = await runSource("name = ask \"Name?\"\nsay name\n", {
  readInput(prompt) {
    return "Maya";
  },
  writeOutput(text) {
    output.push(text);
  },
});
```

Language errors are returned as failed results instead of being thrown.

## `RuntimeIO`

`RuntimeIO` keeps the interpreter independent from browsers, terminals, and
test runners.

```ts
type RuntimeIO = {
  readInput(prompt: string): string | Promise<string>;
  writeOutput(text: string): void;
};
```

`ask` calls `readInput`. `say` calls `writeOutput`.

## `SticksLiteError`

```ts
const error = new SticksLiteError(
  "SyntaxError",
  "Missing colon.",
  2,
  8,
  "Did you forget a colon after this block?",
);
```

Errors include:

- `name`
- `message`
- `line`
- `column`
- optional `hint`
- `format()`

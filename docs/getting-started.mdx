# Quick Start

This page gets you from an empty folder to a running Sticks Lite program.

## 1. Install the CLI

```sh
npm install -g sticks-lite
```

Check that the command is available:

```sh
sticks --version
```

## 2. Create `main.slite`

```slite
say "Hello, world!"
```

## 3. Run it

```sh
sticks main.slite
```

You should see:

```txt
Hello, world!
```

## 4. Add input

`ask` reads text. Use `toNumber` when the answer should be used in math.

```slite
name = ask "Name?"
age = toNumber(ask "Age?")

say "Hello " + name
say "Next year: " + toText(age + 1)
```

## 5. Add a decision

Blocks start with `:` and use indentation.

```slite
score = 87

if score >= 90:
    say "A"
orif score >= 80:
    say "B"
otherwise:
    say "Keep practicing"
```

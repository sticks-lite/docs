# Installation and CLI

The `sticks` command runs `.slite` source files and project folders.

## Requirements

Install a current long-term support version of Node.js. Then check:

```sh
node --version
npm --version
```

## Install

Install Sticks Lite globally so `sticks` is available in the terminal.

```sh
npm install -g sticks-lite
```

## Run a file

```sh
sticks main.slite
```

Only `.slite` source files can be run.

## Run a folder

If you pass a folder, Sticks Lite looks for `main.slite` inside it.

```sh
sticks ./student-project
```

Recommended layout:

```txt
student-project/
  main.slite
  notes.txt
```

The filename must be exactly `main.slite` on Windows, macOS, and Linux.

## Update

```sh
npm update -g sticks-lite
```

Teachers should test lesson files before updating classroom machines.

## Common CLI errors

| Situation | Fix |
| --- | --- |
| Wrong extension | Rename the source file to end in `.slite`. |
| Missing file | Check the path or run from a folder with `main.slite`. |
| Empty folder | Add `main.slite`. |
| `Main.slite` instead of `main.slite` | Rename it exactly. |

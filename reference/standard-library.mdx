# Standard Library

Built-ins are always available. Their names are protected and cannot be used as
variables, constants, or function names.

## Built-ins

| Built-in | Category | Purpose |
| --- | --- | --- |
| `random(min, max)` | Math | Pick a random number in a range. |
| `length(value)` | Collections | Count characters or items. |
| `toNumber(value)` | Conversion | Convert numeric text to a number. |
| `toText(value)` | Conversion | Convert any value to text. |
| `isNumber(value)` | Type check | Check for a number. |
| `isText(value)` | Type check | Check for text. |
| `isList(value)` | Type check | Check for a list. |
| `isTuple(value)` | Type check | Check for a tuple. |
| `isDictionary(value)` | Type check | Check for a dictionary. |
| `isBoolean(value)` | Type check | Check for `True` or `False`. |
| `isNull(value)` | Type check | Check for `null`. |
| `push(list, value)` | Lists | Add to the end of a list. |
| `insert(list, index, value)` | Lists | Insert before an index. |
| `remove(list, index)` | Lists | Remove at an index. |
| `round(number)` | Math | Round to the nearest whole number. |
| `floor(number)` | Math | Round down. |
| `ceiling(number)` | Math | Round up. |
| `absolute(number)` | Math | Distance from zero. |

## Conversion

```slite
score = 42
say "Score: " + toText(score)
```

```slite
age = toNumber("13")
say toText(age + 1)
```

## Type Checks

```slite
say toText(isNumber(42))
say toText(isText("hello"))
say toText(isList([1, 2, 3]))
say toText(isTuple((1, 2)))
say toText(isDictionary({"name": "Maya"}))
say toText(isBoolean(True))
say toText(isNull(null))
```

## Collections

```slite
say toText(length("hello"))
say toText(length([1, 2, 3]))
say toText(length((1, 2)))
say toText(length({"name": "Maya"}))
```

```slite
items = [1, 2]
push(items, 3)
insert(items, 0, 0)
remove(items, 2)
say toText(items)
```

## Math

```slite
say toText(random(1, 6))
say toText(round(3.6))
say toText(floor(3.9))
say toText(ceiling(3.1))
say toText(absolute(-5))
```

## Errors

Built-ins report ordinary Sticks Lite errors:

| Error | Common cause |
| --- | --- |
| `ArgumentError` | Wrong number of arguments. |
| `TypeError` | Wrong value type. |
| `ValueError` | Invalid value, such as `toNumber("abc")`. |
| `IndexError` | List index is outside the valid range. |

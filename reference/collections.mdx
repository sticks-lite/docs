# Lists, Tuples, and Dictionaries

Collections store multiple values and support indexing.

## Lists

Lists use square brackets and are mutable.

```slite
items = [1, 2, 3]
items[0] = 9
push(items, 4)
say toText(items)
```

Expected output:

```txt
[9, 2, 3, 4]
```

## Tuples

Tuples use parentheses, require at least two items, and are immutable.

```slite
point = (10, 20)
say toText(point[1])
```

Expected output:

```txt
20
```

Empty tuples, one-item tuples, and trailing commas are not supported.

## Dictionaries

Dictionaries use quoted text keys and are mutable.

```slite
person = {"name": "Maya"}
person["age"] = 13
say person["name"]
say toText(person["age"])
```

Expected output:

```txt
Maya
13
```

Dictionary keys must be text.

## Indexing

| Value | Index type | Result |
| --- | --- | --- |
| text | whole number | one-character text |
| list | whole number | item at index |
| tuple | whole number | item at index |
| dictionary | text | value for key |

Indexes for text, lists, and tuples start at `0`.

## Mutable collection assignment

Only lists and dictionaries can be assigned by index.

```slite
scores = [90, 85]
scores[1] = 88

profile = {"name": "Maya"}
profile["name"] = "Ari"

say toText(scores)
say profile["name"]
```

Expected output:

```txt
[90, 88]
Ari
```

## Unsupported operations

| Operation | Result |
| --- | --- |
| Assigning into a tuple | `TypeError` |
| List index outside range | `IndexError` |
| Dictionary key missing | `KeyError` |
| Dictionary iteration with `foreach` | `TypeError` |
| `push`, `insert`, or `remove` on a tuple | `TypeError` |

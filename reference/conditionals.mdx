# Conditionals

Conditionals choose between blocks.

## Syntax

```slite
score = 87

if score >= 90:
    say "A"
orif score >= 80:
    say "B"
otherwise:
    say "Keep practicing"
```

Expected output:

```txt
B
```

`orif` blocks are optional. `otherwise:` is optional and must be last.

## Boolean-only conditions

The condition in `if`, `orif`, and `loopif` must evaluate to `True` or
`False`.

```slite
items = [1, 2, 3]

if length(items) > 0:
    say "Has items"
```

Expected output:

```txt
Has items
```

Raw numbers, text, lists, tuples, dictionaries, and `null` are not treated as
truthy or falsey values.

## Parentheses

Conditions do not use surrounding parentheses.

```txt
if score > 5:
    say "ok"
```

## Error cases

| Case | Error |
| --- | --- |
| `orif` without preceding `if` | `SyntaxError` |
| `otherwise` without preceding `if` | `SyntaxError` |
| `orif` after `otherwise` | `SyntaxError` |
| Non-boolean condition | `TypeError` |

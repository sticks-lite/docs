# Operators

Operators combine or update values.

## Operator table

| Group | Operators |
| --- | --- |
| Math | `+`, `-`, `*`, `/`, `%`, `div` |
| Comparison | `<`, `<=`, `>`, `>=`, `==`, `!=` |
| Boolean | `and`, `or`, `not` |
| Assignment | `=`, `+=`, `-=`, `*=`, `/=`, `%=` |
| Increment | `++`, `--` |
| Indexing | `value[index]` |

## Math

```slite
say toText(7 + 3)
say toText(7 - 3)
say toText(7 * 3)
say toText(7 / 2)
say toText(7 div 2)
say toText(7 % 2)
```

Expected output:

```txt
10
4
21
3.5
3
1
```

`div` uses integer division by truncating toward zero.

## Text plus

`+` can join two text values.

```slite
say "Hello " + "Maya"
```

Expected output:

```txt
Hello Maya
```

Use `toText(...)` before combining numbers with text.

## Boolean operators

```slite
age = 13
hasPermission = True

if age >= 13 and hasPermission:
    say "Ready"
```

Expected output:

```txt
Ready
```

Both sides of `and` and `or` must be boolean.

## Assignment operators

```slite
score = 10
score += 5
score--
say toText(score)
```

Expected output:

```txt
14
```

Compound assignment, `++`, and `--` work only with variable names, not indexed
collection entries.

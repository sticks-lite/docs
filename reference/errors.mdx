# Errors

Sticks Lite errors name the problem, show a line and column, and often include
a hint.

```txt
NameError at line 2, column 5: `score` does not exist yet.
Hint: Create it first with `score = ...`, or check the spelling and capitalization.
```

## Error Names

| Error | Meaning |
| --- | --- |
| `SyntaxError` | The source text is not valid Sticks Lite syntax. |
| `IndentationError` | A block is indented incorrectly. |
| `NameError` | A name does not exist or is protected. |
| `TypeError` | A value has the wrong type. |
| `ValueError` | A value has the right type but an invalid content. |
| `MathError` | A math operation cannot be completed. |
| `ConstantError` | A constant was defined or changed incorrectly. |
| `IndexError` | An index is not valid. |
| `KeyError` | A dictionary key does not exist. |
| `FunctionError` | A function is defined or called incorrectly. |
| `ArgumentError` | A call has the wrong number of arguments. |
| `RuntimeError` | A runtime rule was broken. |

## Common Fixes

| Problem | Fix |
| --- | --- |
| Missing `:` | Put `:` at the end of the block-opening line. |
| Misplaced `orif` | Start with `if`, then place `orif` directly after an `if` block. |
| Misplaced `otherwise` | Use `otherwise:` as the final block in an `if` chain. |
| Mixed indentation | Use one indentation style. Four spaces are recommended. |
| Text and number with `+` | Convert the number with `toText(...)`. |
| Raw number in `if` | Compare explicitly, such as `score > 0`. |

## Handling Errors

Use `attempt` only when the program can recover.

```slite
attempt:
    number = toNumber("abc")
when ValueError:
    say "Use digits, like 42."
when error:
    say "Something unexpected happened."
```

`when error` catches every Sticks Lite error and should be last.

## CLI Errors

The `sticks` CLI checks the path before running source code.

| Situation | Fix |
| --- | --- |
| File is not `.slite` | Rename the file or pass a `.slite` source file. |
| File does not exist | Check the path. |
| Folder is empty | Add `main.slite`. |
| Folder has `Main.slite` | Rename it exactly to `main.slite`. |

# Errors

Sticks Lite reports errors with a name, source location, message, and optional
hint.

## Error format

```txt
NameError at line 1, column 5: `score` does not exist yet.
Hint: Create it first with `score = ...`, or check the spelling and capitalization.
```

`runSource(...)` returns formatted language errors in `RunResult.error`. The
CLI writes formatted errors to standard error and exits with code `1`.

## Error names

| Error name | Common cause |
| --- | --- |
| `SyntaxError` | Missing colon, invalid `orif`, unfinished string, bad statement shape. |
| `IndentationError` | Mixed indentation or indentation that does not match a block. |
| `NameError` | Undefined variable or protected name overwrite. |
| `TypeError` | Value has the wrong type for an operation. |
| `ValueError` | Value is the right type but not valid, such as `toNumber("abc")`. |
| `MathError` | Division, modulo, or integer division by zero. |
| `ConstantError` | `DEFINE` misuse or constant overwrite. |
| `IndexError` | Invalid list, tuple, or text index. |
| `KeyError` | Missing dictionary key. |
| `FunctionError` | Invalid function definition or calling a non-function. |
| `ArgumentError` | Wrong number of arguments. |
| `RuntimeError` | Runtime-only rule violation, such as `return` outside a function. |

## Handling errors

```slite
attempt:
    number = toNumber("abc")
    say toText(number)
when ValueError:
    say "Use digits, like 42."
when error:
    say "Something unexpected happened."
```

Expected output:

```txt
Use digits, like 42.
```

`when error` catches any Sticks Lite error and should be last.

## Beginner error guide

| Problem | Likely error | Fix |
| --- | --- | --- |
| Missing `:` after `if`, `repeat`, `new`, or `attempt` | `SyntaxError` | Put `:` at the end of the block-opening line. |
| Bad indentation | `IndentationError` | Use one indentation style. Four spaces are recommended. |
| Unfinished string | `SyntaxError` | Add the matching closing quote on the same line. |
| Standalone `orif` | `SyntaxError` | Start with `if`, then add `orif`. |
| `otherwise` without `if` | `SyntaxError` | Use `otherwise:` only at the end of an `if` chain. |
| Undefined variable | `NameError` | Create the name first or check capitalization. |
| Wrong argument count | `ArgumentError` | Pass exactly the parameters the function expects. |
| Invalid indexing | `IndexError`, `KeyError`, or `TypeError` | Check index type, range, or dictionary key spelling. |
| Bad collection operation | `TypeError` | Use list operations only on lists. |
| Bad type conversion | `ValueError` or `TypeError` | Pass numeric text to `toNumber(...)`. |
| Constant overwrite | `ConstantError` | Use a new variable name instead. |
| Built-in overwrite | `NameError` | Do not assign to protected names such as `toText`. |

## Errors that are not caught

`attempt` catches Sticks Lite language errors. Host environment errors outside
the interpreter, such as unexpected JavaScript exceptions in an embedding app,
are not converted into Sticks Lite error handlers.

# Language Reference

This page defines the core Sticks Lite {{STICKS_LITE_VERSION_LABEL}} language
rules.

## Program Shape

| Rule | Meaning |
| --- | --- |
| Source files | Use the `.slite` extension. |
| Entry file | Folder projects run `main.slite`. |
| Execution | Top-level statements run from top to bottom. |
| Functions | Function definitions are collected before top-level code runs. |
| Statements | Use one statement per line. |
| Blocks | Start with `:` and indent the next lines. |

```slite
say toText(double(5))

new double(x):
    return x * 2
```

## Comments

```slite
# line comment
x = 1 # comment beside code

/*
block comment
*/
say "Done"
```

Comment markers inside text stay part of the text.

```slite
say "# not a comment"
say "/* not a comment */"
```

## Values

| Type | Example |
| --- | --- |
| number | `42`, `3.14` |
| text | `"Maya"`, `'Maya'` |
| boolean | `True`, `False` |
| null | `null` |
| list | `[1, 2, 3]` |
| tuple | `(1, 2)` |
| dictionary | `{"name": "Maya"}` |

## Names

Identifiers may contain letters, digits, and underscores. They may not start
with a digit.

```slite
score = 10
player_score = 20
playerScore = 30
```

Names are case-sensitive. `score` and `Score` are different names.

## Keywords

```txt
DEFINE if orif otherwise repeat times loopif foreach in
break continue new return True False null and or not div
say ask attempt when error
```

Built-in function names and error names are protected.

## Variables and Constants

Create or update a variable with `=`.

```slite
score = 0
score = score + 1
```

`DEFINE` creates a global constant. Constants cannot be changed.

```slite
DEFINE MAX_SCORE = 100
```

## Operators

| Group | Operators |
| --- | --- |
| Math | `+`, `-`, `*`, `/`, `%`, `div` |
| Comparison | `<`, `<=`, `>`, `>=`, `==`, `!=` |
| Boolean | `and`, `or`, `not` |
| Assignment | `=`, `+=`, `-=`, `*=`, `/=`, `%=` |
| Increment | `++`, `--` |

Text can use `+` with text.

```slite
name = "Maya"
say "Hello " + name
```

Convert numbers before combining them with text.

```slite
score = 10
say "Score: " + toText(score)
```

## Conditionals

Conditions must evaluate to `True` or `False`.

```slite
if score >= 90:
    say "A"
orif score >= 80:
    say "B"
otherwise:
    say "Keep practicing"
```

## Loops

```slite
repeat 3 times:
    say "Practice"
```

```slite
count = 3

loopif count > 0:
    say toText(count)
    count--
```

`foreach` works with lists and tuples.

```slite
scores = [90, 85, 100]

foreach score in scores:
    say toText(score)
```

Dictionary iteration is not supported in Sticks Lite {{STICKS_LITE_VERSION_LABEL}}.

## Functions

```slite
new add(left, right):
    return left + right

say toText(add(2, 3))
```

Functions have local scope. Blocks such as `if` and `repeat` do not create a
new scope.

## Collections

Lists and dictionaries can be changed.

```slite
items = [1, 2]
items[0] = 9

person = {"name": "Maya"}
person["age"] = 13
```

Tuples cannot be changed.

```slite
point = (10, 20)
say toText(point[0])
```

Indexes start at `0`.

## Errors

Use `attempt` with one or more `when` handlers.

```slite
attempt:
    value = toNumber("abc")
when ValueError:
    say "Not a number"
when error:
    say "Something else happened"
```

`when error` catches any Sticks Lite error and should be last.

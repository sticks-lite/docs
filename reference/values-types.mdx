# Values and Types

Sticks Lite has a small set of runtime value types.

## Type table

| Type | Literal examples | Notes |
| --- | --- | --- |
| number | `42`, `3.14` | Used for math and numeric comparison. |
| text | `"Maya"`, `'Maya'` | Can be joined with other text using `+`. |
| boolean | `True`, `False` | Required for conditions. |
| null | `null` | Represents no value. |
| list | `[1, 2, 3]` | Mutable, indexed from `0`. |
| tuple | `(10, 20)` | Immutable, at least two items. |
| dictionary | `{"name": "Maya"}` | Mutable, keyed by text. |
| function | `new double(x):` | User-defined callable value. |
| built-in | `toText` | Protected callable value. |

## Text

```slite
first = "Ada"
last = 'Lovelace'
say first + " " + last
```

Expected output:

```txt
Ada Lovelace
```

Escape sequences inside strings include `\n` and `\t`.

## Booleans

Comparisons return booleans.

```slite
score = 10
say toText(score > 5)
```

Expected output:

```txt
True
```

## Null

Functions that finish without `return` produce `null`.

```slite
new greet:
    say "Hello"

value = greet()
say toText(isNull(value))
```

Expected output:

```txt
Hello
True
```

## Collections

```slite
items = [1, 2]
point = (10, 20)
profile = {"name": "Maya"}

say toText(items[0])
say toText(point[1])
say profile["name"]
```

Expected output:

```txt
1
20
Maya
```

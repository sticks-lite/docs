# Installation

Install Sticks Lite from npm so the `sticks` command is available in the
terminal.

## Requirements

Sticks Lite requires Node.js 18 or newer.

```sh
node --version
npm --version
```

## Install globally

```sh
npm install -g sticks-lite
```

Check the installed command:

```sh
sticks --version
```

## Run a source file

```sh
sticks main.slite
```

## Run a folder

```sh
sticks .
```

When a folder is passed, the CLI looks for `main.slite` inside that folder.

## Update

```sh
npm update -g sticks-lite
```

Teachers should test lesson files before updating classroom machines.

## Uninstall

```sh
npm uninstall -g sticks-lite
```

# CLI

The `sticks` CLI runs Sticks Lite programs from files and folders.

## Basic usage

```sh
sticks main.slite
sticks .
sticks ./student-project
```

With no argument, `sticks` runs `main.slite` from the current directory.

## Version

```sh
sticks --version
sticks -v
```

The version printed by the CLI comes from the installed package metadata.

## Prompts

`ask` prompts are written to standard output. If the prompt does not end with
whitespace, the CLI adds a single space before reading input.

```slite
name = ask "Name?"
say "Hello " + name
```

In a terminal, the prompt appears as:

```txt
Name? 
```

## Errors

Language errors and file errors are written to standard error. The CLI exits
with code `1` when an error occurs.

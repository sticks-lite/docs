# Running .slite Files

A Sticks Lite project can be a single file or a folder with `main.slite`.

## Single file

```txt
lesson/
  greeting.slite
```

Run it:

```sh
sticks lesson/greeting.slite
```

## Folder project

```txt
student-project/
  main.slite
  notes.txt
```

Run the folder:

```sh
sticks student-project
```

The entry file must be named exactly `main.slite`.

## Direct file extension

Only `.slite` files can be run as direct file inputs.

```sh
sticks main.slite
```

If a file has another extension, the CLI reports a `FileError`.

## Directory errors

| Situation | Fix |
| --- | --- |
| Folder is empty | Add `main.slite`. |
| Folder has `lesson.slite` but no `main.slite` | Rename or add `main.slite`. |
| Folder has `Main.slite` | Rename it exactly to `main.slite`. |
| Path cannot be read | Check file permissions. |

# Classroom Use

Sticks Lite is intended for monitored educational environments: classrooms,
clubs, camps, tutoring, and beginner computer-science lessons.

## Good fit

- introducing variables, values, decisions, loops, functions, and collections
- practicing terminal-based program runs
- reading friendly error messages with students
- writing short `.slite` files during lessons

## Classroom setup

1. Install Node.js 18 or newer.
2. Install Sticks Lite globally.
3. Give each student a folder with `main.slite`.
4. Run `sticks .` from the project folder.

```sh
npm install -g sticks-lite
sticks .
```

## Learning boundaries

Sticks Lite is intentionally small. It is for learning programming concepts,
not production applications.

## Teacher note

Review programs before students run them, especially when lessons include input
or shared files. Keep the focus on clear code, visible output, and readable
errors.

# Debugging with Students

Debugging is part of learning the language. Sticks Lite errors are designed to
give students a location and a next step.

## Read the location first

Error messages include a line and column.

```txt
SyntaxError at line 2, column 12: An `if` statement needs `:` before its block.
Hint: Put `:` at the end of the block-opening line, then indent the next line.
```

Start by finding that line together.

## Check the common causes

| Symptom | First check |
| --- | --- |
| Syntax error | Missing `:`, quote, bracket, or closing parenthesis. |
| Indentation error | Mixed tabs/spaces or a line not aligned with its block. |
| Name error | Spelling, capitalization, or a variable used before assignment. |
| Type error | Text used as a number, raw number used as a condition, or wrong collection type. |
| Argument error | Too few or too many values in a call. |

## Make one change

Change one line, run the program again, and compare the new error or output.
This keeps debugging visible and calm.

## Use small probes

Add temporary `say` statements to inspect values.

```slite
score = toNumber(ask "Score?")
say "Debug score: " + toText(score)
```

Remove probes after the program is working.

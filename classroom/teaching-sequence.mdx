# Teaching Sequence

This sequence works well for first programming lessons.

## 1. Output and input

Start with `say`, then add `ask`.

```slite
name = ask "Name?"
say "Hello " + name
```

## 2. Values and variables

Introduce numbers, text, booleans, and `toText(...)`.

```slite
score = 10
say "Score: " + toText(score)
```

## 3. Decisions

Use comparisons before `if`.

```slite
score = 87

if score >= 80:
    say "Passing"
otherwise:
    say "Keep practicing"
```

## 4. Loops

Teach `repeat`, then `loopif`, then `foreach`.

```slite
repeat 3 times:
    say "Practice"
```

## 5. Functions

Name reusable work.

```slite
new double(value):
    return value * 2

say toText(double(5))
```

## 6. Collections and errors

Introduce lists before dictionaries. Add `attempt` when students already know
what error they expect.

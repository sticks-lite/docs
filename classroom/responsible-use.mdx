# Responsible Use

Sticks Lite is for monitored learning environments.

## Use it with guidance

Students should use Sticks Lite with a teacher, mentor, parent, or club leader
who can review lesson files and help interpret errors.

## Keep examples appropriate

Use examples that match the classroom goal. Short programs, predictable input,
and visible output are best for early lessons.

## Know the boundary

Sticks Lite is not a security sandbox and is not meant for production software.
The language core has no direct file-system or network APIs, but the CLI still
reads source files from the computer running it.

## Simple rule

Run programs you understand in an environment you supervise.

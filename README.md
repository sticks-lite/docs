# Sticks Lite Documentation

This repository contains the documentation site for Sticks Lite v1.0.

Sticks Lite is an educational programming language developed by Kabir Sekhon
for monitored classroom environments. The docs explain installation, the CLI,
the interpreter, language syntax, built-ins, examples, error messages, and
distribution.

## Run Locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Sticks Lite Installation

The compiler/interpreter package is distributed through npm:

```sh
npm install -g sticks-lite
sticks main.slite
```

## Repositories

- Browser IDE: `sticks-lite-browser-ide`
- Documentation: `sticks-lite-docs-site`
- Compiler/interpreter: `sticks-lite-language`

# Sticks Lite

Sticks Lite {{STICKS_LITE_VERSION_LABEL}} is a small classroom programming
language for first programs. It teaches beginning computer-science concepts
with readable syntax, indentation-based blocks, friendly errors, and a compact
interpreter.

## First Program

```slite
say "Hello, world!"
```

## Why Sticks Lite

- It is intentionally small.
- It uses one statement per line.
- It teaches variables, conditionals, loops, functions, collections, and errors.
- It runs from the `sticks` CLI or from classroom tools that embed the interpreter.
- It is intended for monitored educational environments.

## Install

```sh
npm install -g sticks-lite
sticks --version
sticks main.slite
```

## Example

```slite
score = 87

if score >= 90:
    say "A"
orif score >= 80:
    say "B"
otherwise:
    say "Keep practicing"
```

## Responsible Use

Sticks Lite is for supervised learning settings. It is not a sandbox, a
production application platform, or a tool for unsupervised execution of
untrusted source files.

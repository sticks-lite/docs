# Sticks Lite

Sticks Lite {{STICKS_LITE_VERSION_LABEL}} is an educational programming
language for monitored classroom environments. Programs are saved as `.slite`
files and run with the `sticks` command.

## Install

```sh
npm install -g sticks-lite
```

## Run

```sh
sticks main.slite
sticks .
```

## First program

```slite
say "Hello, world!"
```

## Language core

Sticks Lite teaches variables, `DEFINE` constants, strings, numbers, booleans,
`null`, lists, tuples, dictionaries, indexing, conditionals, loops, functions,
`attempt` and `when`, friendly errors, built-ins, the CLI, and the public
TypeScript API.

## Classroom use

Use Sticks Lite in guided lessons. Run programs you understand in an
environment you supervise.

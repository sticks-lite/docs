# Responsible Use

Sticks Lite is for supervised learning. Use it in settings where a teacher,
mentor, or parent can review lesson files, explain errors, and decide what is
appropriate for the group.

## Simple Guidance

- Run programs that are part of the lesson or have been reviewed.
- Keep student projects small enough to discuss.
- Do not use Sticks Lite as a security sandbox.
- Do not run unknown source files without classroom controls.
- Use friendly errors as teaching moments, not as a substitute for supervision.

## Why This Matters

The language core has no direct file-system or network APIs, but the CLI reads
source files and interacts with the terminal. Sticks Lite is a teaching tool,
not a production runtime or isolation system.

## Classroom Wording

You can tell students:

> Sticks Lite is for class projects we can read and understand together. If you
> find a file from somewhere else, ask before running it.

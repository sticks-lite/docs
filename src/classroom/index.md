# Classroom Use

Sticks Lite is intended for monitored educational environments. A teacher,
mentor, or parent should decide what students run and how each lesson fits the
class.

## What Sticks Lite Is Useful For

- Introducing variables, values, and output.
- Practicing conditionals with explicit boolean conditions.
- Comparing counted loops, condition loops, and collection loops.
- Writing small functions with parameters and returns.
- Reading and updating simple collections.
- Learning from friendly error messages.

## What to Keep Small

Sticks Lite works best when programs are short enough to read together. For a
new concept, keep the first example under one screen and ask students to change
one part at a time.

## Starter Routine

1. Create the project with `sticks init lesson-one`.
2. Open `lesson-one/main.slite`.
3. Run `sticks run` from inside the project folder.
4. Read the first error together if one appears.
5. Change one line.
6. Run again.

# Learn Sticks Lite

This learning path teaches Sticks Lite in the order students usually need it:
output, values, decisions, loops, functions, collections, and recoverable
errors.

## Start here

Use this section when you want guided explanations and small examples. Each
lesson introduces one concept, shows the expected output, and calls out common
mistakes.

## Lesson order

1. Your First Program
2. Variables and Values
3. Decisions with `if`, `orif`, `otherwise`
4. Loops
5. Functions
6. Collections
7. Handling Errors with `attempt` and `when`
8. Classroom Practice Programs

## A complete first example

```slite
name = ask "Name?"
say "Hello " + name
```

Expected output depends on the input. If the student enters `Maya`, the program
prints:

```txt
Hello Maya
```

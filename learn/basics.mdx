# Learn the Basics

This guide teaches the core ideas in the order students usually need them.

## You will learn

- Printing output
- Storing values
- Reading input
- Making decisions
- Repeating work
- Grouping data
- Writing functions
- Handling expected errors

## Output

Use `say` to print one value.

```slite
say "Hello, world!"
```

Use `toText` when printing a number with text.

```slite
score = 10
say "Score: " + toText(score)
```

## Variables

Variables store values for later.

```slite
score = 0
score += 10
score++
say toText(score)
```

## Input

`ask` returns text.

```slite
name = ask "What is your name?"
say "Hello " + name
```

Convert text before doing math.

```slite
age = toNumber(ask "Age?")
say "Next year: " + toText(age + 1)
```

## Decisions

Conditions must be `True` or `False`.

```slite
score = 87

if score >= 90:
    say "A"
orif score >= 80:
    say "B"
otherwise:
    say "Keep practicing"
```

## Loops

Use `repeat` when the count is known.

```slite
repeat 3 times:
    say "Practice"
```

Use `loopif` when the program decides when to stop.

```slite
count = 3

loopif count > 0:
    say toText(count)
    count--
```

## Collections

Lists can change.

```slite
scores = [90, 85, 100]
push(scores, 95)
say toText(scores)
```

Tuples cannot change.

```slite
point = (10, 20)
say toText(point[0])
```

Dictionaries use text keys.

```slite
profile = {"name": "Maya", "age": 13}
say profile["name"]
```

## Functions

Functions name reusable work.

```slite
new square(x):
    return x * x

say toText(square(5))
```

## Expected errors

Use `attempt` when the program can recover.

```slite
attempt:
    age = toNumber("not a number")
when ValueError:
    say "Use digits like 13."
```

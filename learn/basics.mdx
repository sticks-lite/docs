# Tutorial

This tutorial introduces Sticks Lite in the order a student is likely to meet it in class.

## First Program

Use `say` to print text.

```slite
say "Hello, world!"
```

The program has one statement. Sticks Lite runs it from top to bottom.

## Variables

Variables store values.

```slite
score = 0
score += 10
score++
say toText(score)
```

The final value is `11`.

## Input

`ask` returns text.

```slite
name = ask "What is your name?"
say "Hello " + name
```

Convert text to a number when you want arithmetic.

```slite
age = toNumber(ask "Age?")
say "Next year: " + toText(age + 1)
```

## Branching

Use `if`, `orif`, and `otherwise`.

```slite
score = 87

if score >= 90:
    say "A"
orif score >= 80:
    say "B"
otherwise:
    say "Keep practicing"
```

Every condition must be boolean.

## Repetition

Use `repeat` when the count is known.

```slite
repeat 3 times:
    say "Practice"
```

Use `loopif` when the condition decides when to stop.

```slite
count = 3

loopif count > 0:
    say toText(count)
    count--
```

## Collections

Lists hold ordered values and can be changed.

```slite
scores = [90, 85, 100]
push(scores, 95)
```

Tuples are ordered but cannot be changed.

```slite
point = (10, 20)
```

Dictionaries use text keys.

```slite
profile = {"name": "Maya", "age": 13}
say profile["name"]
```

## Functions

Functions name reusable behavior.

```slite
new square(x):
    return x * x

say toText(square(5))
```

Functions create their own local scope.

## Errors

Errors are part of learning. Sticks Lite errors say what happened and where.

```slite
attempt:
    age = toNumber("not a number")
when ValueError:
    say "Use digits like 13."
```

Use `attempt` only when the program can recover.

# Your First Program

A Sticks Lite program is saved in a `.slite` file. The usual first file is
named `main.slite`.

## Print text

```slite
say "Hello, world!"
```

Expected output:

```txt
Hello, world!
```

`say` prints one value. Text values can use double quotes or single quotes.

## Ask for input

`ask` reads text from the user.

```slite
name = ask "What is your name?"
say "Hello " + name
```

If the user enters `Maya`, expected output is:

```txt
Hello Maya
```

## Run it

```sh
sticks main.slite
```

You can also run a folder that contains `main.slite`:

```sh
sticks .
```

## Common mistakes

| Mistake | What to change |
| --- | --- |
| `say("Hello")` | Write `say "Hello"` without parentheses. |
| `ask("Name?")` | Write `ask "Name?"` without parentheses. |
| File named `main.txt` | Rename it to `main.slite`. |
| Two statements on one line | Put each statement on its own line. |

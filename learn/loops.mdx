# Loops

Loops repeat work.

## Repeat a known number of times

```slite
repeat 3 times:
    say "Practice"
```

Expected output:

```txt
Practice
Practice
Practice
```

The repeat count must be a whole number and cannot be negative.

## Loop while a condition is true

```slite
count = 3

loopif count > 0:
    say toText(count)
    count--
```

Expected output:

```txt
3
2
1
```

The `loopif` condition must be `True` or `False`.

## Loop over a collection

```slite
scores = [90, 85, 100]

foreach score in scores:
    say toText(score)
```

Expected output:

```txt
90
85
100
```

`foreach` supports lists and tuples. Dictionary iteration is unsupported in
Sticks Lite v1.

## Stop or skip

```slite
items = [1, 2, 3, 4]

foreach item in items:
    if item == 2:
        continue
    if item == 4:
        break
    say toText(item)
```

Expected output:

```txt
1
3
```

## Common mistakes

| Mistake | What happens |
| --- | --- |
| `repeat 2.5 times:` | Repeat counts must be whole numbers. |
| `repeat -1 times:` | Repeat counts cannot be negative. |
| `foreach key in {"a": 1}:` | Dictionaries cannot be used with `foreach` in v1. |
| `break` outside a loop | Sticks Lite reports a `RuntimeError`. |

# Handling Errors with attempt and when

Some programs can recover from expected errors. Use `attempt` with one or more
`when` handlers.

## Catch one error

```slite
attempt:
    age = toNumber("abc")
    say toText(age)
when ValueError:
    say "Use digits like 13."
```

Expected output:

```txt
Use digits like 13.
```

`toNumber("abc")` raises a `ValueError`, so the matching handler runs.

## Add a catch-all handler

```slite
attempt:
    value = toNumber("abc")
    say toText(value)
when ValueError:
    say "That was not a number."
when error:
    say "Something else happened."
```

Expected output:

```txt
That was not a number.
```

`when error` catches any Sticks Lite error and should be the last handler.

## Common mistakes

| Mistake | What happens |
| --- | --- |
| `attempt:` without `when` | The parser reports a syntax error. |
| `when` without `attempt` | The parser asks for an `attempt:` block first. |
| Unknown handler name | Use a built-in error name such as `ValueError`. |
| Specific `when` after `when error` | Put `when error` last. |

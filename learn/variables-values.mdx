# Variables and Values

Variables give names to values so a program can use them later.

## Create a variable

```slite
score = 10
say toText(score)
```

Expected output:

```txt
10
```

Numbers are printed with `toText(...)` when they are combined with text.

```slite
score = 10
say "Score: " + toText(score)
```

Expected output:

```txt
Score: 10
```

## Update a variable

```slite
score = 0
score += 5
score++
say toText(score)
```

Expected output:

```txt
6
```

`+=`, `-=`, `*=`, `/=`, and `%=` update an existing variable. `++` and `--`
add or subtract one.

## Constants

Use `DEFINE` for a value that should not change.

```slite
DEFINE MAX_SCORE = 100
say toText(MAX_SCORE)
```

Expected output:

```txt
100
```

`DEFINE` is top-level only. It cannot be placed inside an `if`, loop, function,
or `attempt` block.

## Common mistakes

| Mistake | What happens |
| --- | --- |
| Using a name before creating it | Sticks Lite reports a `NameError`. |
| Changing a `DEFINE` constant | Sticks Lite reports a `ConstantError`. |
| Assigning to `random` or `toText` | Built-in names are protected. |
| Writing `"Score: " + score` | Convert the number with `toText(score)`. |
